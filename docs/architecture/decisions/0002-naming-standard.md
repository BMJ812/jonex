# ADR 0002: Naming standard

- Status: Accepted
- Date: 2026-08-02

## Decision

Use `JØNEX` for public-facing branding and prose.

Use the ASCII slug `jonex` for:

- Repository and filesystem paths
- Cargo package and crate names
- npm package scopes
- Application identifiers
- Environment variables
- Plugin identifiers and namespaces
- URLs and command names

## Rationale

The branded form preserves the intended identity. The ASCII form avoids
encoding ambiguity and ecosystem restrictions in technical identifiers.
